# AI Email Classification System

## Project Overview
This is an AI-powered email classification system built for students. It classifies emails into **Assignments**, **Notices**, **Personal**, and **Spam** using a Machine Learning model (TF-IDF + Logistic Regression).

## Features
- **Smart Classification**: automatically categorizes incoming emails.
- **Project Structure**:
    - **Backend**: FastAPI (Python)
    - **Frontend**: Vanilla JS + HTML (Dark Mode UI)
    - **Database**: SQLite
- **Auth**: Secure Login/Register system.

## How to Run in VS Code (Recommended)
This project is configured for **Visual Studio Code**.

1.  Open this folder in VS Code.
2.  Click the **Run and Debug** icon on the left sidebar (Play/Bug icon).
3.  Select **"Run Email Classifier"** from the top dropdown.
4.  Click the **Green Play Button** (▷).
5.  Open **http://localhost:8000** in your browser.

## Manual Run
If you prefer the terminal:
```bash
python -m backend.main
```
